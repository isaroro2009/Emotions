# ✨ Sentia - Emotion Detector Web App ✨

Sentia es una aplicación web futurista diseñada para detectar sentimientos a través del texto y la voz. 
Utiliza la potencia de **Google Gemini AI** para el análisis emocional y la **Web Speech API** para el dictado.

## 🚀 Características
- 🎤 **Voz a Texto**: Háblale a la app y deja que transcriba tus emociones.
- 🧠 **Análisis Profundo**: Detecta Felicidad, Tristeza, Enojo, Ansiedad y más.
- 🎨 **Interfaz Kawaii-Futurista**: Colores neón, bordes suaves y feedback visual instantáneo.
- 📱 **Responsive**: Úsala desde tu celular o computadora.

## 🛠️ Tecnologías
- **React.js** + **Vite**
- **Tailwind CSS** (Estilizado)
- **Lucide React** (Iconografía)
- **Gemini API** (Inteligencia Artificial)

## 📦 Instalación
1. Clona el repositorio: `git clone https://github.com/tu-usuario/sentia-app.git`
2. Instala dependencias: `npm install`
3. Crea un archivo `.env` y añade tu: `VITE_GEMINI_API_KEY=tu_llave_aqui`
4. Corre el proyecto: `npm run dev`
